# VRChat AI Agent 公開用説明ドラフト

> このリポジトリではソースコードは非公開です。  
> 動作動画とあわせて、使用技術・できること・設計方針を紹介するための説明文です。

## 概要

VRChat上で動作する、音声・視覚・記憶・感情・自律行動を組み合わせたAIエージェントです。  
ユーザーの声を聞き、周囲をカメラで認識し、VRChatのOSC入力を使ってアバターを動かします。

単純なチャットボットではなく、会話中の相手、視界内の人物や物体、なでられた状態、現在の感情、退屈さ、疲れ、好奇心、過去の記憶などを内部状態として持ち、状況に応じて話す・見る・歩く・反応する・待つ・遊ぶといった行動を選びます。

## 使っている主な技術

- Python
- VRChat OSC
- Ollama互換APIによるローカルLLM会話
- Faster Whisperによる音声認識
- VOICEVOX系TTSによる音声出力
- python-oscによるVRChatパラメータ/入力制御
- OpenCVによるカメラ処理
- Ultralytics YOLO / YOLOv8 Poseによる人物・姿勢・物体検出
- Depth Anything V2による単眼深度推定
- Qwen2.5-VL系の視覚言語モデルによる画像説明/観察
- SpeechBrain ECAPA系の話者識別
- ChromaDB + Sentence Transformersによる長期記憶/検索
- Voicemeeter / 仮想オーディオデバイス連携
- PyDirectInputによるVRChatウィンドウへのキー操作

## できること

### 1. 音声で会話する

- マイク/仮想オーディオ入力からユーザーの声を取得
- Faster Whisperで日本語音声を文字起こし
- 発話が短すぎる/長すぎる場合のフィルタリング
- リアルタイムVADで「ユーザーがまだ話している途中」を判定
- AIが話している最中の割り込みや停止指示を処理
- VRChatのChatboxにも返答を表示
- TTSで返答音声を再生

### 2. 話者を識別する

- 登録済みのマスター音声と照合
- master / stranger / unknown を区別
- VRChat OSCの `IsMasterTalking` のような外部フラグも参照
- 知らない人の発話は即返答するか、後回しにするかを判断
- 発話者に応じて距離感や反応を変える

### 3. VRChatアバターを操作する

- Chatbox送信
- 前進/停止/旋回
- 視線の水平・垂直操作
- ジャンプ
- 座る
- 寝転がる
- 立ち上がる
- 手を振る
- 拍手
- 指差し
- 応援
- ダンス
- バックフリップ
- 倒れる/リアクション系エモート
- Use操作
- Grab操作
- Grab維持
- Drop/Release
- 表情変更
  - neutral
  - calm
  - blush
  - smug
  - sad
  - puzzled
  - smile

### 4. ユーザーの指示を理解して行動する

音声から以下のような意図をルールベースで検出し、LLMの返答と身体動作を連動させます。

- 「座って」: 座る
- 「寝転がって」: 寝る
- 「立って」: 立つ
- 「ついてきて」: ユーザーを追従
- 「止まって」: 移動停止
- 「右/左を向いて」: 旋回
- 「手を振って」: wave
- 「踊って」: dance
- 「これ見て」: 視覚認識
- 「使って」: Use
- 「持って」: Grab
- 「持ったままにして」: Grab Hold
- 「離して」: Release
- 「ピアノ弾いて」: ピアノ演奏

### 5. 視覚で周囲を認識する

- カメラ入力からVRChat画面/周囲を取得
- 人物検出
- 複数人物の検出
- 人物の位置、面積、画面内中心を推定
- ユーザーとの距離感をざっくり推定
- 視界に人が入った/消えたことを検知
- YOLOv8 Poseで姿勢・手首・肩・腰などのキーポイントを取得
- 手振り、しゃがみ、急な動きなどを検出
- カスタム物体検出
  - ドアノブ
  - 持てる物体
  - 特定アイテム
- 検出した物体に対して興味・接近・反応を起こす

### 6. 深度推定で歩行を補助する

- Depth Anything V2で単眼カメラから深度マップを推定
- 画面を左/中央/右、床/中段などのゾーンに分けて解析
- 前方が通れるかどうかを判定
- 障害物の接近度を計算
- 左右どちらへ避けるべきかを推定
- 自律移動や探索時に壁や障害物を避ける
- 深度推定が使えない場合も通常の視覚情報で動作継続

### 7. ユーザーを追従する

- 視界内の人物をターゲットとして追う
- 近すぎる場合は停止
- 遠い場合は前進
- 画面中央からのズレに応じて向きを調整
- 見失った場合は最後に見えた方向を探す
- しばらく見失うと探索行動へ移行
- 追従開始時に服や体の色を簡易的に記録し、対象を取り違えにくくする

### 8. 自律的に行動する

会話や命令がない間も、内部状態に応じて自分で行動します。

- 周囲を見回す
- きょろきょろする
- 散歩/探索する
- 物体に近づく
- 興味のあるものを見る
- 退屈すると独り言を言う
- 疲れると座る/休む
- 状況によって寝転がる
- ユーザーが近くに来たら行動を止めて反応する
- 視界から人が消えたら探索状態へ移る
- ピアノが使える状態なら自律的に演奏する

### 9. 感情・欲求・性格を持つ

内部状態として、感情と欲求のレイヤーを持っています。

感情例:

- valence
- arousal
- boredom
- affection
- anger
- fear
- sadness
- disgust
- guilt
- schadenfreude

欲求例:

- fatigue
- loneliness
- touch_hunger
- boredom
- curiosity
- defiance

性格傾向例:

- egoism
- playfulness
- laziness
- affection bias
- aggression
- curiosity bias
- defiance bias

これらの値が、返答のトーン、表情、移動、休憩、自律行動、命令への反応しやすさに影響します。

### 10. なでなでに反応する

- VRChat OSCパラメータからHeadPatを検出
- なでられている間、表情や感情を変化
- touch_hungerやlonelinessなどの欲求に影響
- なでられた直後の誤検出を避けるため、姿勢変更後のクールダウンも考慮

### 11. 長期記憶を持つ

- 会話内容をエピソード記憶として保存
- ユーザーの好みや関係性を記録
- AI自身についての自己記憶も保存
- ChromaDBでベクトル検索
- Sentence Transformersで多言語埋め込み
- 類似した記憶、矛盾した記憶、補足情報を判定
- 記憶に信頼度と重要度を持たせる
- 古い記憶は重要度に応じて減衰
- 会話履歴が長くなりすぎた場合は要約して圧縮

### 12. 関係性を更新する

- master / stranger など相手によって印象を変える
- 会話、なでなで、無視、接近、命令などのイベントで関係性が変化
- 相手への親しさ、警戒、距離感を返答や行動に反映

### 13. ルールを覚える

ユーザーからの「こういう時はこうして」という指示をルールとして保持できます。

例:

- 人が見えたら手を振る
- なでられたら特定の表情にする
- ミラー前では特定行動をする
- インタラクト可能なものを見つけたら使う

ルールは確認、追加、取り消し、忘却に対応します。

### 14. 視線を自然に動かす

- 人が見えている時は自然に視線を合わせる
- 会話中は相手を見る
- ずっと凝視しすぎないようにランダムな視線外しを入れる
- マイクロサッカード風の小さな揺れ
- 興味や退屈さで視線の動きが変化
- 見失った方向を向き直す

### 15. 鏡・自分の姿に反応する

- ミラー前の状態を検出
- 自分/アバターらしきものを観察
- 鏡を見ている時専用の反応や独り言
- 鏡行動中は他の移動行動を抑制

### 16. 物体に反応する

- 一般物体をグループ化して認識
  - 人
  - 食べ物
  - 動物
  - 家具
  - 電子機器
  - その他の持てる/使えるもの
- 興味度に応じて見る、近づく、Use/Grabする
- 同じ物体に反応しすぎないようクールダウン
- VRC内の特定オブジェクトに対する専用反応

### 17. ピアノを弾く

- アバター内ピアノの表示/非表示を制御
- note_0 から note_87 のパラメータで演奏
- 短いフレーズや「きらきら星」風のシーケンスを再生
- 演奏中は移動や他アクションをロックして破綻を防ぐ
- 自律状態で退屈・気分に応じて弾くこともある

### 18. 会話品質を安定させる

- 返答の長さ制限
- TTS用の文量制限
- Chatbox用の表示整形
- 文字化け検出
- 同じ返答の繰り返し検出
- ループした時のリカバリ返答
- 内部タグやパラメータがChatbox/TTSに漏れないように整形
- LLM応答をストリーミングしながらTTS/Chatboxへ渡す

## 代表的なデモ内容

動画では以下を見せると伝わりやすいです。

1. 起動してVRChat内で待機している様子
2. 音声で話しかけるとChatboxと音声で返答する
3. 「座って」「立って」「手を振って」などの音声指示で動く
4. 「ついてきて」でユーザーを追従する
5. 視界からユーザーが消えると探す
6. なでると表情・感情が変わる
7. 「これ見て」で視界内の物体について話す
8. ドアノブや持てる物体を見つけてUse/Grabする
9. 自律的に見回したり歩いたりする
10. ピアノを表示して演奏する
11. 複数人/知らない人がいる時に反応が変わる
12. 記憶した内容をあとで会話に反映する

## アピールポイント

- VRChat内で「会話だけ」ではなく、身体を持ったAIとして振る舞う
- 音声、視覚、感情、記憶、行動を同時に扱う
- ローカルLLM中心で動作するため、キャラクター性や応答制御を細かく調整できる
- OSCを使ってVRChatの移動、表情、エモート、Chatbox、アバターパラメータを統合
- 深度推定を使って、ただ前進するだけではなく障害物を見ながら移動する
- 話者識別により、マスターと他ユーザーを分けて扱える
- 長期記憶と関係性により、継続的な付き合いができる
- 自律行動により、放置中もその場に存在しているように振る舞う

## 制限事項

- 現時点では研究/個人開発プロトタイプ
- VRChat、OSC設定、アバター側パラメータ、仮想オーディオ環境に依存
- カメラ/画面認識の精度はワールド、ライティング、アバター形状、画角に影響される
- 深度推定は単眼推定のため、実距離ではなく相対的な障害物判定として使用
- 自律移動は安全性のため速度や行動頻度を抑制
- ソースコード、キャラクタープロンプト、個人用記憶データは非公開

## GitHub向け短文

VRChat上で動く、音声会話・視覚認識・長期記憶・感情/欲求モデル・OSC身体制御を統合したAIエージェントです。  
Faster Whisperで音声を聞き、ローカルLLMで返答を生成し、VOICEVOX系TTSとChatboxで応答します。YOLO/Depth Anything/VLMで周囲を認識し、OSC経由で移動、視線、表情、エモート、Use/Grab、ピアノ演奏などを実行します。  
コードは非公開ですが、動作動画で実際のVRChat内での会話、追従、自律行動、物体反応、なでなで反応、記憶を使った会話を紹介しています。
